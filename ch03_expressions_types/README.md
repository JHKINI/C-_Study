# 3장. 표현식과 자료형

> 교재 예제를 직접 입력하고 VS Code + MinGW g++로 빌드·실행하며 익힌 코드입니다.

**다룬 내용**: 리터럴, 연산자 우선순위와 결합 방향, 암묵적·명시적 형변환, 오버플로우·언더플로우, 진법 출력(`dec`/`oct`/`hex`), 입출력 조정자(`boolalpha`, `setprecision`)

- `Prg3-30.cpp`(초 → 시·분·초)는 [`01_my_projects/time_convert`](../01_my_projects/time_convert)에서 **일(day) 단위까지 나누고 `%` 연산으로 다시 짠 버전**으로 확장했습니다.
- 필기: 2진수·10진수·16진수로 바꿨을 때 어떻게 표현되는지 자연스럽게 계산할 수 있도록 연습하기 → 직접 만든 계산기에서 결과를 `bitset<32>`(2진수)와 `hex`(16진수)로 출력해 봄
