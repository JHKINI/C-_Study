# 6장. 함수

> 교재 예제를 직접 입력하고 VS Code + MinGW g++로 빌드·실행하며 익힌 코드입니다.

**다룬 내용**: `<cmath>` 수학 함수, 난수, `void` 함수, **값으로 전달 vs 참조로 전달**, 기본 매개변수, 오버로딩, 지역·전역 변수 셰도잉, 범위 해결 연산자 `::`, `static` 변수

- 필기: 자주 쓰는 함수는 위에 정의하고, 선언과 정의를 나눌 수 있다 (→ 7장 헤더 분리로 이어짐)

## 예제 목록

| 파일 | 내용 |
|---|---|
| `Prg6-1.cpp` | <cmath> 헤더 파일에 정의되어 있는 숫자 함수들을 사용하는 프로그램 |
| `Prg6-2.cpp` | 이차 방정식 근을 찾는 프로그램 |
| `Prg6-3.cpp` | 삼각 함수 프로그램 |
| `Prg6-4.cpp` | 변의 개수와 길이를 입력받고 정다각형의 둘레와 넓이를 구하는 프로그램 |
| `Prg6-5.cpp` | 알파벳의 개수를 세고, 소문자를 모두 대문자로 변경하는 프로그램 |
| `Prg6-6.cpp` | time(0) 함수를 사용해서 현재 시간을 찾는 프로그램 |
| `Prg6-7.cpp` | 랜덤 숫자를 사용한 추측 게임 |
| `Prg6-8.cpp` | void 함수를 사용해 인사말을 출력하는 프로그램 |
| `Prg6-9.cpp` | 매개변수가 있는 void 함수를 사용하여 패턴을 출력하는 프로그램 |
| `Prg6-10.cpp` | 사용자로부터 양의 정수를 입력 받는 함수를 정의하고 가장 오른쪽 숫자를 출력하는 프로그램 |
| `Prg6-11.cpp` | 사용자로부터 입력 받은 두 양의 정수 중에 어떤 숫자가 더 큰지 확인하는 함수를 정의하고 활용하는 프로그램 |
| `Prg6-12.cpp` | 연도를 나타내는 정수를 입력받는 함수, 윤년인지 확인하는 함수, 결과를 출력하는 함수를 정의하고 활용하는 프로그램 |
| `Prg6-13.cpp` | 값으로 전달 메커니즘에서 parameters의 변경이 arguments에 영향을 주지 않는다는 것을 확인하는 프로그램 |
| `Prg6-14.cpp` | 참조로 전달 메커니즘에서 parameter의 변경이 argument에 영향을 준다는 것을 확인하는 프로그램 |
| `Prg6-15.cpp` | 참조로 전달 메커니즘을 사용해서 두 값을 스왑(swap)하는 프로그램 |
| `Prg6-16.cpp` | 함수에서 값을 리턴하는 것을 보여주는 간단한 프로그램 |
| `Prg6-17.cpp` | 입력, 처리, 출력 함수들을 사용해서 학생 점수를 기반으로 등급을 계산하는 프로그램 |
| `Prg6-18.cpp` | 기본 매개변수를 사용하는 프로그램 |
| `Prg6-19.cpp` | 서로 다른 시그니처를 같은 함수 3개를 오버로딩하는 예를 보여주는 프로그램 |
| `Prg6-20.cpp` | 내부 블록과 외부 블록에 선언되어 있는 지역 변수에서 일어나는 셰도잉을 확인하는 프로그램 |
| `Prg6-21.cpp` | 전역 변수의 셰도잉을 확인하는 프로그램 |
| `Prg6-22.cpp` | 범위 해결 연산자를 사용하는 프로그램 |
| `Prg6-23.cpp` | 자동 지역 변수를 확인하는 프로그램 |
| `Prg6-24.cpp` | 정적 변수를 확인하는 프로그램 |
| `Prg6-25.cpp` | 변수의 초기화를 확인하는 프로그램 |
| `Prg6-26.cpp` | 함수를 사용해서 정기 예금의 미래 가치를 찾는 프로그램 |
| `Prg6-27.cpp` | 함수들을 활용해서 정기 적금의 미래 가치를 찾는 프로그램 |

## 빌드

```bash
g++ -std=c++17 Prg파일.cpp -o app && ./app
```
