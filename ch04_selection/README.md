# 4장. 선택 (조건문)

> 교재 예제를 직접 입력하고 VS Code + MinGW g++로 빌드·실행하며 익힌 코드입니다.

**다룬 내용**: `if`, `if-else`, 다중 분기, `switch`와 `break`, 조건부 표현식(`? :`)

- 윤년 판별(`Prg4-9`), 소득 구간별 세금(`Prg4-16`), 그 해의 몇 번째 날인지 계산(`Prg4-17`)처럼 조건이 여러 겹인 문제를 연습

## 예제 목록

| 파일 | 내용 |
|---|---|
| `Prg4-1.cpp` | if 조건문을 사용해서 절대값을 계산하고 출력하는 프로그램 |
| `Prg4-2.cpp` | if 조건문을 사용해서 초과 근무 시간이 있는 급여 계산하기 |
| `Prg4-3.cpp` | if-else 조건문을 사용해서 합격/불합격 학점 찾기 |
| `Prg4-4.cpp` | if-else 조건문을 사용해서 입력받은 더 큰 숫자 또는 숫자가 같을 경우 첫 번째 숫자를 출력하는 프로그램 |
| `Prg4-5.cpp` | 입력받은 두 숫자가 왼쪽이 더 큰지, 같은지, 더 작은지 출력하는 프로그램 |
| `Prg4-6.cpp` | 여러 방향 조건 분기를 사용해서 학점을 찾는 프로그램 |
| `Prg4-7.cpp` | 자동차를 대여할 수 있는 나이 범위를 확인하는 프로그램 |
| `Prg4-8.cpp` | 특정한 온도 범위에 따라 에어컨을 냉방 또는 난방으로 가동하는 프로그램 |
| `Prg4-9.cpp` | 3가지 조건을 확인하여 윤년을 찾는 프로그램 |
| `Prg4-10.cpp` | switch 조건문을 사용해서 특정 요일부터 마지막 요일까지 출력하는 프로그램 |
| `Prg4-11.cpp` | switch 조건문과 break 구문을 조합해서 요일을 출력하는 프로그램 |
| `Prg4-12.cpp` | switch 조건을 사용해서 점수를 기반으로 학점 출력하기 |
| `Prg4-13.cpp` | switch 조건문을 사용해서 pass/fail 학점 찾기 |
| `Prg4-14.cpp` | 두 숫자를 입력 받은 뒤에 두 숫자 중에 더 큰 숫자 또는 같을 경우 첫 번째 숫자를 조건부 표현식으로 찾아 출력하기 |
| `Prg4-15.cpp` | 학생 점수를 3개 입력 받고 최소값과 최대값을 기반으로 평균을 구해서 학생의 성적을 찾는 프로그램 |
| `Prg4-16.cpp` | 4가지 서로 다른 소득 범위를 기반으로 세금을 계산해서 출력하는 프로그램 |
| `Prg4-17.cpp` | 몇 월 며칠을 입력 받았을 때 해당 날짜가 올해 몇 번째 날짜인지 구하는 프로그램 |

## 빌드

```bash
g++ -std=c++17 Prg파일.cpp -o app && ./app
```
