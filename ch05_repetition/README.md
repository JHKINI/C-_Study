# 5장. 반복

> 교재 예제를 직접 입력하고 VS Code + MinGW g++로 빌드·실행하며 익힌 코드입니다.

**다룬 내용**: 카운터·센티넬·EOF 제어 `while`, `for`, `do-while`(입력값 검사), 중첩 반복(별·숫자 패턴, 구구단표)

- `Prg5-7`, `Prg5-8`은 같은 폴더의 `numbers.dat`을 읽습니다.
- 필기: 안쪽 `for`가 다 돈 뒤에 바깥 `for`의 `i++`가 실행된다 (2차원 처리에 중첩 for가 필요한 이유)

## 예제 목록

| 파일 | 내용 |
|---|---|
| `Prg5-1.cpp` | while 반복문을 사용해서 메시지를 10회 출력하기 |
| `Prg5-2.cpp` | 카운터 제어 while 반복문을 사용해서 학생 점수의 평균을 구하는 프로그램 |
| `Prg5-3.cpp` | while 반복문을 사용해서 0부터 n-1까지 출력하는 프로그램 |
| `Prg5-4.cpp` | while 반복문으로 수열의 합 구하기 |
| `Prg5-5.cpp` | 센티넬 제어 while 반복문을 사용해서 숫자들의 합 찾기 |
| `Prg5-6.cpp` | EOF 제어 while 반복문을 사용해 키보드로 입력한 숫자들의 합을 구하는 프로그램 |
| `Prg5-7.cpp` | EOF 제어 while 반복문을 사용해서 파일에 저장된 숫자들의 합을 구하는 프로그램 |
| `Prg5-8.cpp` | EOF와 플래그를 사용해서 반복문 종료하기 |
| `Prg5-9.cpp` | 0부터 n-1까지 for 반복문으로 출력하기 |
| `Prg5-10.cpp` | 1~300의 범위에 있는 7로 나눌 수 있는 정수를 10개의 열을 가진 표 형식으로 출력하는 프로그램 |
| `Prg5-11.cpp` | 한 달의 날짜 수와 첫 날의 요일을 입력 받고 달력 형태로 한 달을 출력하는 프로그램 |
| `Prg5-12.cpp` | 사용자로부터 정수를 입력받고 do-while을 이용하여 가장 왼쪽으로 숫자를 출력하는 프로그램 |
| `Prg5-13.cpp` | do-while 반복문을 데이터 유효성 검사에 사용하는 프로그램 |
| `Prg5-14.cpp` | 반복문을 중첩해서 * 기호를 정해진 패턴으로 출력하는 프로그램 |
| `Prg5-15.cpp` | 반복문을 중첩해서 숫자를 정해진 패턴으로 출력하는 프로그램 |
| `Prg5-16.cpp` | 반복문을 중첩해서 2~10 범위를 갖는 크기의 곱셈 표를 출력하는 프로그램 |
| `Prg5-17.cpp` | 소수를 찾았을 때 return 구문을 실행하는 프로그램 어떤 숫자가 1인지 또는 복합수인지 또는 소수인지 확인하면 곧바로 main 함수를 벗어남 |
| `Prg5-18.cpp` | 리스트의 크기를 처음부터 정했을 때 리스트 내부 숫자의 합과 곱을 구하는 프로그램 |
| `Prg5-19.cpp` | 리스트 내부의 숫자 곱을 활용해서 팩토리얼(n!)을 구하는 프로그램 |
| `Prg5-20.cpp` | 반복문을 사용해서 밑을 지수 번만큼 곱해서 거듭제곱을 구하는 프로그램 |
| `Prg5-21.cpp` | 정수 리스트의 크기를 미리 알고 있을 때 정수 리스트 내부의 최소값과 최대값을 구하는 프로그램 |
| `Prg5-22.cpp` | 리스트 내부에 있는 요소 중 적어도 하나가 7로 나눌 수 있는지 확인하는 프로그램 |

## 빌드

g++ -std=c++17 Prg파일.cpp -o app && ./app
