# 8장. 배열

> 교재 예제를 직접 입력하고 VS Code + MinGW g++로 빌드·실행하며 익힌 코드입니다.

**다룬 내용**: 배열 입출력, 파일에서 배열로 읽기, 배열을 함수에 전달, 병렬 배열, 객체 배열, 2차원 배열, 빈도 배열·히스토그램

## 예제 목록

| 파일 | 내용 |
|---|---|
| `Prg8-1.cpp` | 배열을 사용해서 정수 목록을 읽어 들이고 거꾸로 돌려서 출력하는 프로그램 |
| `Prg8-2.cpp` | 어떤 파일을 읽고 배열을 사용해서 정수 목록을 읽어 들이고 거꾸로 돌려서 다른 파일에 출력하는 프로그램 |
| `Prg8-3.cpp` | 어떤 달의 날짜 수를 배열을 사용해서 출력하는 프로그램 |
| `Prg8-4.cpp` | 컴파일한 Circle 클래스를 활용해서 Circle 객체의 배열을 만드는 프로그램 |
| `Prg8-5.cpp` | 파일에서 정수를 배열로 읽어 들인 뒤 숫자의 합계, 평균, 최소값, 최대값을 출력하는 프로그램 |
| `Prg8-6.cpp` | 배열의 이름과 크기를 매개변수로 입력 받아서 출력하는 함수를 사용하는 프로그램 |
| `Prg8-7.cpp` | 배열의 이름과 크기를 매개변수로 입력받아서 수정하는 함수를 사용하는 프로그램 |
| `Prg8-8.cpp` | 2개의 배열을 매개변수로 받고 유사적으로 리턴하는 함수를 사용하는 프로그램 |
| `Prg8-9.cpp` | 병렬 행렬을 사용하여 5명의 이름, 점수, 학점을 저장하고 활용하는 프로그램 |
| `Prg8-13.cpp` | 학생의 시험 성적들과 그 평균을 2차원 배열로 만들어서 활용하는 프로그램 |
| `Prg8-14.cpp` | 파일에서 0~9 범위의 정수를 읽어 들이고 빈도 배열과 히스토그램을 만들어서 출력하는 프로그램 |
| `Prg8-15.cpp` | 2차원 배열을 열 방향과 행 방향으로 선형 변환해서 1차원 배열로 만든 뒤 출력하는 프로그램 |

| 폴더 | 파일 | 교재 번호 | 빌드 |

- `Prg8-2`, `Prg8-5`, `Prg8-14`는 같은 폴더의 `.dat` 파일을 읽습니다.
