# 9장. 참조 · 포인터 · 동적 메모리

> 교재 예제를 직접 입력하고 VS Code + MinGW g++로 빌드·실행하며 익힌 코드입니다.

**다룬 내용**: 참조 변수, 참조로 전달·리턴, 주소 연산자와 포인터, 포인터로 배열 다루기, 2차원 배열을 포인터로 전달, **힙 메모리(`new`/`delete`)와 래기드 배열**, 동적 메모리를 쓰는 클래스(Course, Matrix)

## 예제 목록

| 파일 | 내용 |
|---|---|
| `Prg9-1.cpp` | 원본 변수와 참조 변수를 선언하고 초기화 한 뒤에 각각의 변수를 사용해 값에 접근하는 방법을 보여주는 프로그램 |
| `Prg9-2.cpp` | 참조로 전달을 사용해서 함수로 전달한 2개의 값을 스왑하는 프로그램 |
| `Prg9-3.cpp` | 두 쌍의 분수를 만들고 larger 함수를 호출해서 둘 중에 큰 값을 찾는 프로그램 |
| `Prg9-4.cpp` | 3개의 변수를 선언하고 값과 주소를 출력하는 프로그램 |
| `Prg9-5.cpp` | 데이터 변수의 값에 직접 또는 간접 접근해서 출력하는 프로그램 |
| `Prg9-6.cpp` | 포인터로 전달을 사용해서 함수로 전달한 2개의 값을 스왑하는 프로그램 |
| `Prg9-7.cpp` | 두 쌍의 분수를 만들고 larger 함수를 호출해서 둘 중에 큰 값을 찾는 프로그램 |
| `Prg9-8.cpp` | 시스템이 배열에 있는 요소를 포인터로 다룬다는 것을 확인하기 위한 프로그램 |
| `Prg9-9.cpp` | 인덱스와 포인터 모두를 활용해서 배열의 요소에 접근하는 방법을 보여주는 프로그램 |
| `Prg9-10.cpp` | 포인터를 사용해서 배열의 요소에 접근하는 방법을 보여주는 프로그램 |
| `Prg9-11.cpp` | 포인터를 사용해서 배열을 거꾸로 만드는 프로그램 |
| `Prg9-12.cpp` | 함수의 매개변수로 2차원 배열을 포인터로 전달해서 출력하는 프로그램 |
| `Prg9-13.cpp` | 프로그램이 존재하는 동안 계속해서 메모리에 존재하는 전역 변수, 정적 변수를 사용하는 프로그램 |
| `Prg9-14.cpp` | 힙 메모리에 크기가 유동적인 배열을 만들고 포인터로 요소에 접근하는 프로그램 |
| `Prg9-15.cpp` | 힙에 동적으로 래기드 배열을 할당해서 이항계수를 찾는 프로그램 |
